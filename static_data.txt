================================================================================
SHC STOCK — ARCHIVED STATIC / HARDCODED DATA
================================================================================
This file is a permanent archive of every static/hardcoded data list that
used to live directly in the Flutter source code, before each module was
made fully dynamic (backend API + PostgreSQL via Prisma, Dio-based
ApiClient). The source files have since had these blocks DELETED (they were
previously kept as commented-out code for reference; that reference now
lives here instead).

Where the exact same data was also seeded into the database via a backend
script, that script is noted — run it again any time to restore this
reference data into a fresh/empty DB.

Archived: 2026-08-09
================================================================================
